# Wake-Mate ⚡ (Remote Alarm untuk Pasangan)

Aplikasi alarm jarak jauh (*remote alarm*) khusus pasangan dengan desain modern **Neubrutalism**. Dibuat untuk membangunkan pasangan yang susah bangun dan suka mengaktifkan mode hening (*silent*).

---

## 🌟 Fitur Utama

- 🚨 **Tembus Mode Hening (*Silent Mode Bypass*)**: Alarm tetap berbunyi kencang di volume 100% meskipun HP penerima dalam mode senyap.
- ⚡ **Alarm Kilat Jarak Jauh**: Bunyikan alarm di HP pasangan secara instan dari jarak jauh.
- ⏰ **Kunci Jadwal Jam**: Pasang jadwal jam bangun (misal 06:30 pagi) langsung di HP pasangan.
- 🎵 **Suara Kustom TikTok & MP3**: Unggah sound viral TikTok atau lagu MP3 pilihanmu sebagai nada dering alarm.
- 🎙️ **Rekam Suara Sendiri**: Rekam suara ucapan bangun langsung dari mikrofon.
- 🎯 **Misi Bangun (Anti-Mati Sendiri)**: Pasangan wajib mengetuk tombol bangun sebanyak 3 kali berturut-turut agar alarm mati total.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend**: React 19, Vite, Lucide Icons, Canvas Confetti
- **Backend Server**: Node.js, Express, Socket.io (Realtime WebSockets)
- **Mobile Container**: Capacitor 8 (Android Native Wrapper)
- **Bahasa & Kompilasi**: Java 17, Gradle 8.5+, Android SDK
